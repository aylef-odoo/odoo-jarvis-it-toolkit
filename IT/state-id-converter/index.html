Province / Cantoni → state_id/id

Carica un CSV o Excel: rilevo la colonna provincia (IT) o cantone (CH), capisco se è in sigla o nome esteso, e la converto negli external ID nativi di Odoo (base.state_it_xx / base.state_ch_xx).

Per la Svizzera riconosco i 26 cantoni in tedesco, italiano e francese (es. Zürich, Ticino, Genève) e li mappo sul record canonico base.state_ch_xx. Alcune sigle coincidono tra i due Paesi (AG, GE, FR, SO, LU…): seleziona il Paese giusto, oppure usa Auto per un file con contatti di più Paesi. In Auto, se il file ha una colonna Country/Paese la uso per assegnare a ogni riga il Paese corretto (incluse le sigle ambigue); senza quella colonna converto solo i valori riconosciuti in un unico Paese.

L'elaborazione avviene interamente nel browser. base.state_it_* e base.state_ch_* sono gli external ID nativi del modulo base di Odoo.
